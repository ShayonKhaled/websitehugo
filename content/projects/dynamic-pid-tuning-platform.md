## Overview

A hardware and software test platform for tuning PID parameters on RoboMaster M3508 motors under repeatable conditions.

## Problem

Manual tuning was inconsistent and time-consuming. I needed a repeatable way to observe response and iterate faster.

## What I built

- A repeatable motor test setup
- Data-driven tuning workflow
- Iterative comparison of PID parameter sets

## Stack

- Embedded control
- Motor drivers and sensors
- Robotics test tooling
