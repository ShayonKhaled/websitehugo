## Deploying to GitHub Pages

This repository includes a GitHub Actions workflow at `.github/workflows/hugo.yml` that builds and deploys the site.

To deploy:
1. Go to **Repository Settings → Pages**.
2. Set **Source** to **GitHub Actions**.
3. Push or merge changes to the `main` branch.

The workflow will build the Hugo site and publish it to GitHub Pages automatically.
